# Processed Data

This folder contains the final customer-level dataset prepared for predictive modeling in the Olist Customer Purchase Analytics project.

## Purpose

The processed dataset is the output of the customer data preparation stage. It combines historical customer purchasing behavior with a future repeat-purchase target so that the data can be used for supervised machine learning.

The dataset is generated by:

`notebooks/01_Customer_Data_Preparation.ipynb`

## Contents

| File | Description |
|---|---|
| `modeling_data.csv` | Final customer-level feature dataset used by the modeling notebook |

## Dataset Structure

The dataset has one row per customer and contains the following fields:

| Column | Description |
|---|---|
| `customer_unique_id` | Customer-level identifier |
| `recency` | Number of days since the customer's most recent historical purchase relative to the analysis cutoff |
| `frequency` | Number of unique historical delivered orders |
| `monetary` | Total historical order value |
| `average_order_value` | Average historical order value |
| `repeat_purchase` | Target indicating whether the customer made at least one future delivered purchase |

## Target Definition

The `repeat_purchase` target is created using future purchasing behavior after the historical cutoff.

```text
1 = customer made at least one future delivered purchase
0 = customer did not make a future delivered purchase
```

The historical customer features are calculated before the future period is used to create the target. This keeps future purchasing behavior separate from the model inputs.

## Data Flow

```text
Cleaned Olist Data
        ↓
Customer Data Preparation
        ↓
Historical Customer Features
        ↓
Future Purchase Target
        ↓
modeling_data.csv
        ↓
Model Training & Evaluation
```

## Usage

This dataset is loaded by:

`notebooks/02_Model_Training_&_Evaluation.ipynb`

The notebook uses the following columns as model features:

```text
recency
frequency
monetary
average_order_value
```

The `repeat_purchase` column is used as the prediction target.

## Important Note

This is a processed modeling dataset rather than a raw transactional dataset.

The original Olist tables contain different levels of granularity, while this file has been transformed into a customer-level analytical dataset suitable for machine learning.
